# VALDEUD OS — MIND

Prototype initial de l’interface VALDEUD OS\.

## Fichiers

- `index.html` : structure de la page\.
- `style.css` : apparence et adaptation mobile\.
- `app.js` : interactions de démonstration\.
- `README.md` : présentation du projet\.

## Lancer

Ouvrir `index.html` dans un navigateur ou utiliser un serveur de prévisualisation\.

## Important

Cette version est une maquette front\-end\. Elle ne contient pas encore de backend, de base de données, de connexion IA, ni de conversation vocale complète\. La dictée vocale dépend du navigateur\.
